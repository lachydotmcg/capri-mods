# Capri // Pad

Tired of your Capri sitting on thin air? Now she has a proper place to perch! Bring your desktop companion to life with a dynamic audio-reactive pad.

- Kind: code mod
- Made by: CyberPhantxm
- Needs: settings, music, and voice permissions

| Feature | Visual Behavior |
|---|---|
| PC Audio | Warm RGB palette that reacts smoothly to your system's audio output. |
| User Voice | Prioritizes your microphone in real-time with a custom 'thinking' purple accent. |
| Hologram Mode | Fully translucent integration when Capri's hologram glass is enabled. |
| Sleeping | The pad displays a terminal status text. |
| Close Button | Functional, clickable "X" button to dismiss the pad instantly. |

**How to use:** Make sure **Auto Perch** is turned ON (checked) in her right-click menu, then spawn the pad easily via manual drag-and-drop. 

- The mod features custom WinMM double-buffered microphone tracking for a smooth, crash-free experience!
