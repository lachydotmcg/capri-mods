# Rusifikator

Русский интерфейс для Капри. Переводит мейнфрейм, настройки, меню, кнопки, подсказки при наведении, названия и описания модов и скинов из каталога. Списки микрофонов, динамиков, моделей и языков не трогает.

Russian UI for Capri. Translates the Mainframe, settings, menus, buttons, hover tips, and the names and descriptions of catalog mods and skins. Device, model and language lists stay as they are.

- Kind: code
- Made by: Tvoi Protivnik помощник Opus 5.5
- Version: 1.0.0

## Как пользоваться

Установи мод и разреши его запуск. Перевод появится сразу. Чтобы вернуть английский, выключи мод во вкладке «Моды».

## Что мод делает и чего не делает

- Меняет только текст интерфейса Капри на русский. Словарь встроен в файл мода.
- Ничего не скачивает из интернета и никуда не отправляет данные.
- Бренды и названия моделей (Arasaka, MaxTac, OpenRouter и т. п.) оставляет как есть.
- Доски шахмат и мини-игр Капри рисует сама, их мод не переводит.
