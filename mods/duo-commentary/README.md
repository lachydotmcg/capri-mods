# Duo Commentary

Real-time commentary mode. Capri narrates what you're doing in serious or roast mode.

## Features

- **Live Commentary** - Capri comments on what she sees
- **Roast Mode** - Sarcastic, savage commentary
- **Serious Mode** - Professional, technical commentary
- **One-shot Explain** - Get a single comment without activating continuous mode
- **Toggle On/Off** - Easy enable/disable

## Commands

- `comment this` - Start live commentary
- `roast mode` - Switch to savage commentary
- `serious mode` - Switch to professional commentary
- `explain this` - Get one comment without starting continuous mode
- `stop commenting` - End commentary
- `commentary help` - Show all commands

## Usage

```
You: "Capri, comment this"
Capri: "Commentary mode on. I'll narrate what I see. Professional style."

You: "roast mode"
Capri: "Switching to roast mode. Let's get savage."

You: "explain this"
Capri: "That code? Yeah, I've seen worse. Not much worse, but I've seen it."

You: "stop commenting"
Capri: "Commentary off. That was 3 comments. You're welcome."
```

## How It Works

Duo Commentary activates a commentary mode where Capri provides observations. In roast mode, she delivers sarcastic commentary. In serious mode, she provides professional observations. The mod randomly selects from curated comment lists based on the mode.

Perfect for streaming, recording tutorials, or just entertainment while you work.
