# Track Commentator

Capri comments on the songs you play, in her own style. English and Russian. She skips ads, and keeps a list of tracks you liked.

- Kind: code mod (runs C#, Capri asks before running it)
- Needs: Capri 0.8.7 or newer, Windows
- Permissions: `music` (reads what is playing), `brain` (asks her brain for a comment)
- Made by: kyltest12

## What she does

- Comments on every 3rd new song by default, a few seconds after it starts, so skipped songs get no comment.
- Ignores videos and ads between songs.
- Each comment is one request to her brain, so it may use your API credits. Raise the number if that matters.

## Commands (say or type, in English or Russian)

| English | Русский |
| --- | --- |
| `comment every 5 tracks` | `комментируй каждые 5 треков` |
| `comment every track` | `комментируй каждый трек` |
| `comments off` / `comments on` | `выключи комментарии` / `включи комментарии` |
| `remember this track` | `запомни этот трек` |
| `favorite tracks` | `любимые треки` |
| `forget favorite tracks` | `забудь любимые треки` |
| `commentator status` | `статус комментатора` |
| `speak English` | `говори по-русски` |
