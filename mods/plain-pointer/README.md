# Plain Pointer

Swaps Capri's pink and red mouse pointer for the normal Windows arrow, on her, her speech bubble, her TYPE / TALK buttons and all her little windows. Turn the mod off and her own pointer comes back.

It works at every screen scale and on every monitor: Capri 0.9.9 draws her pointer separately for each display scaling, and Plain Pointer swaps every one of those sizes, so a window you drag to a 150% or 200% screen keeps the arrow too. On older Capri it swaps her single pointer the same way.

Your own mouse pointer everywhere else is untouched; this only changes the pointer you see over her and her windows.

- Kind: code mod
- Made by: Quaisar_THM
- Needs: Capri with mod API 3 (0.8.7 or newer), Windows

No network access, no keys, nothing sent anywhere.
