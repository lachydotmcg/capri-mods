# Capri Whatsapp

PT: WhatsApp com a Capri; EN: Smart WhatsApp companion

- Kind: code mod
- Made by: BieISG

PORTUGUÊS (BRASIL)

A Capri WhatsApp conecta uma conta pessoal do WhatsApp à Capri Desktop. Pelo Mainframe, você pode consultar conversas e grupos, importar contatos em VCF, pesquisar mensagens por pessoa/palavra/período, criar resumos (últimas 24 horas, desde o último resumo e decisões/tarefas), configurar perfis de notificação (Trabalho, Jogando, Apresentação e Dormindo), transcrever áudios recebidos localmente com Whisper.cpp, acompanhar diagnósticos e controlar o armazenamento. A Capri também explica como usar os recursos quando perguntada. Respostas escritas no estilo pessoal da Capri são opcionais, vêm desativadas por padrão e sempre exigem prévia e confirmação explícita.

INSTALAÇÃO: Capri Mainframe > CAPRI > Mods > Import mod. Importe o arquivo .capri-code, aprove o code mod após revisar o código, abra Options e escaneie o QR Code com WhatsApp > Dispositivos conectados > Conectar dispositivo. Atualizações mantêm o ID técnico capri-whatsapp-companion; não apague a pasta de dados nem whatsapp-runtime.

PRIVACIDADE E SEGURANÇA: este é um code mod, não um plug-in em sandbox. Mods de código podem acessar recursos do PC com as permissões do usuário; instale apenas se confiar no código. Credenciais da sessão, mensagens, transcrições, contatos importados, preferências e logs são armazenados localmente em whatsapp-runtime. A pasta auth contém credenciais sensíveis e nunca deve ser compartilhada. Resumos de grupos/áudios podem enviar conteúdo ao provedor Brain configurado na Capri. A limpeza opcional remove apenas áudios já transcritos e preserva mensagens, transcrições e sessão. O envio de mensagens preparadas exige prévia completa e aprovação afirmativa recente.

AVISO: a conexão pessoal usa Baileys, uma implementação não oficial do protocolo de dispositivos conectados do WhatsApp. Não é afiliada à Meta/WhatsApp e pode sofrer desconexões ou restrições.

ENGLISH

Capri WhatsApp links a personal WhatsApp account to Capri Desktop. From Mainframe, users can browse chats and groups, import contacts from VCF, search by person/keyword/date, create summaries (last 24 hours, since previous summary, decisions/tasks), configure Work/Gaming/Presentation/Sleep notification profiles, transcribe incoming audio locally with Whisper.cpp, review diagnostics, and manage storage. Capri also explains how to use features when asked. Optional written replies use the user's Capri personality, are disabled by default, and always require a full preview and explicit approval.

INSTALLATION: Capri Mainframe > CAPRI > Mods > Import mod. Import the .capri-code file, review and approve the code mod, open Options, then scan the QR code through WhatsApp > Linked devices > Link a device. Updates retain the technical ID capri-whatsapp-companion; do not delete the mod data folder or whatsapp-runtime.

PRIVACY & SECURITY: this is a code mod, not a sandboxed plug-in. Code mods can access PC resources with the user's permissions; install only if you trust the source. Session credentials, messages, transcripts, imported contacts, preferences, and logs are stored locally in whatsapp-runtime. The auth folder contains sensitive credentials and must never be shared. Group/audio summaries may send content to the Brain provider configured in Capri. Optional cleanup removes only audio files that already have transcripts and preserves messages, transcripts, and the session.

NOTICE: the personal-account connection uses Baileys, an unofficial implementation of WhatsApp's linked-device protocol. It is not affiliated with WhatsApp or Meta and may be disconnected or restricted. WhatsApp voice-note replies and arbitrary media sending are not included.
